# 🔐 Tailwind Login Page

A modern and responsive login page built using **HTML5** and **Tailwind CSS**. This project was created to practice Tailwind's utility-first approach by designing a clean authentication interface with a dark theme.

## ✨ Features

- Responsive login form
- Dark-themed user interface
- Centered layout using Flexbox
- Styled email and password input fields
- Rounded card design
- Focus ring effects on input fields
- Hover effect on the login button
- Utility-first styling with Tailwind CSS

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- CSS (Generated with Tailwind CLI)
