# 💰 Pricing Offer Card

A modern and responsive **Pricing Offer Card** built using **HTML5** and **Tailwind CSS**. This project recreates a promotional pricing section with a clean card layout, highlighted savings badge, and an eye-catching call-to-action button using Tailwind's utility-first approach.

## ✨ Features

- Responsive pricing card layout
- Dark background with centered card
- Launch price section
- Highlighted "You save $250" badge
- Large pricing display
- Rounded card and pricing section
- Call-to-action button with hover effects
- Built entirely with Tailwind CSS utility classes

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Tailwind CLI
